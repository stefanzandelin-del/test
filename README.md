# Stopwatch

A simple stopwatch web app designed for iPhone.

## Use it on your iPhone

1. Host the three files (`index.html`, `manifest.webmanifest`, `icon.png`) somewhere reachable over HTTPS (e.g. GitHub Pages), or open `index.html` directly in Safari.
2. In Safari, tap the **Share** button, then **Add to Home Screen**.
3. Launch it from your home screen — it opens full-screen, like a native app.

## Features

- Start / Stop / Lap / Reset
- Hundredths-of-a-second precision
- Best/worst lap highlighting
- Keeps running correctly even if the app is backgrounded or the page reloads
